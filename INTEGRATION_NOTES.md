# Guard Mail futuristic UI integration

The supplied futuristic cybersecurity visual direction has been integrated into the Guard Mail homepage without replacing the existing forensic analyzer.

- `/` is the new Guard Mail landing page.
- `/dashboard` remains the existing functional forensic email analyzer.
- The landing page uses the project's existing `framer-motion` and `lucide-react` dependencies.
- No new runtime dependency was introduced.
- Branding is Guard Mail throughout the homepage.
- Vercel deployment configuration remains included.
